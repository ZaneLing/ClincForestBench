# Synthea sample patient data

Downloaded on 2026-09-08 from the official Synthea sample-data site.

- Project: https://github.com/synthetichealth/synthea
- Dataset page: https://synthetichealth.github.io/synthea/
- Archive: https://synthetichealth.github.io/synthea-sample-data/downloads/synthea_sample_data_csv_apr2020.zip
- Archive filename: `synthea_sample_data_csv_apr2020.zip`
- SHA-256: `4194b18c11eaedcf0d5d5dd448d8ac9661f14381e2ef9f109215dc42266cd38a`

The archive is retained verbatim and extracted into `csv/`. The local sample
contains 1,171 synthetic patients and 16 related CSV tables covering patient
demographics, encounters, conditions, observations, medications, procedures,
care plans, imaging, immunizations, payers, providers, and other EHR entities.

Synthea states that these records are synthetic rather than real patient data
and that generated data can be used without privacy or security restrictions.
See the upstream project and download page for current terms and citation
guidance.
