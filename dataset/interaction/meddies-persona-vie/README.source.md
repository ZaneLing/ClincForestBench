# Meddies Persona VIE MVP source

- Upstream dataset: `Meddies/meddies-persona-vie` on Hugging Face.
- Dataset role: diverse synthetic patient personas and communication behavior.
- Published license metadata: CC BY-NC 4.0.
- Public release: 150,000 Vietnamese synthetic profiles.
- MVP payload: a small Dataset Viewer export; the two roughly 200 MB Parquet
  shards are unnecessary for the initial adapter.
- Provenance URL: https://huggingface.co/datasets/Meddies/meddies-persona-vie

The MVP preserves Vietnamese source text and persona attributes. It does not
claim that ICD-coded history fields are newly adjudicated diagnoses.
