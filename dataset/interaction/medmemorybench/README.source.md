# MedMemoryBench MVP source

- Upstream dataset: `Cyan27/MedMemoryBench` on Hugging Face; official code is
  published by `AQ-MedAI/MedMemoryBench` on GitHub.
- Dataset role: bilingual, 12-month longitudinal medical-agent memory.
- MVP payload: English personas, events, trap events, queries, and clinical
  reports. Large dialogue Parquet files are omitted from the MVP download.
- Provenance URLs:
  - https://huggingface.co/datasets/Cyan27/MedMemoryBench
  - https://github.com/AQ-MedAI/MedMemoryBench

Current upstream license statements differ between the Hugging Face metadata
(CC BY-NC-SA 4.0) and a GitHub README note (CC BY 4.0). ClincForestBench treats
the local payload as non-commercial/share-alike pending clarification and does
not redistribute source rows.
