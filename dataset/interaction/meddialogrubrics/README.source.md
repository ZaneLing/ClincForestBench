# MedDialogRubrics MVP source

- Upstream dataset: `AQ-MedAI/MedDialogRubrics` on Hugging Face.
- Dataset role: case-specific, expert-refined must-ask inquiry references.
- Public release artifact: `MedDialogRubrics_v1.xlsx`.
- MVP use: inspect the real workbook sheets and convert selected case rubrics
  into reference action branches with weights and categories.
- Provenance URLs:
  - https://huggingface.co/datasets/AQ-MedAI/MedDialogRubrics
  - https://arxiv.org/abs/2601.03023

The dataset card does not declare a license. The workbook remains local and
must not be redistributed until the publisher adds explicit terms.
